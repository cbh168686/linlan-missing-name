# 缺名册

一份毕业名册少了一个名字。你的老同学问：**我们班，原来有多少人？**

中文校园悬疑 ARG 网页游戏。以学校官网、个人聊天、旧论坛和档案副本展开调查，包含三种结局。当前为开发试玩版 v0.9.1。

## 游玩

打开发布后的网页，先阅读周栩的邮件与内容提示。通过搜索、对话、发送证据和对照资料推进。卡住时可以使用三级提示，不需要查看源代码。

- 支持电脑与手机浏览器；无需登录或 AI 服务。
- 进度、笔记和聊天记录保存在当前浏览器，可导出存档换设备继续。
- 可关闭动态效果，或单独隐藏恐怖图像与场景；不影响线索与结局。
- 设计目标为 45—70 分钟，尚未完成外部玩家的盲测计时。

## 内容提示

包含虚构邪教、失踪、心理控制、怪异眼部图像与压抑情节，无自动音效或高频闪烁。对内容敏感者请勿游玩；出现不适请立即停止。人物、学校、组织与调查结果均为虚构，游戏中的通信与提交不会联系真实个人或机构。

## 本地运行

在本目录执行：

```sh
python3 -m http.server 8768
```

访问 `http://127.0.0.1:8768/`。使用相对路径，可直接部署到 GitHub Pages 的项目目录或其他静态网站空间。

## 素材说明

校园影像与校徽沿用项目作者提供并授权参考的废弃模板素材，只用于虚构校园日常展示，不对应故事内的违法者或失踪者。眼部纹理、暗红底片背景、守灯像和走廊画面由 AI 为本项目生成。未复制参考游戏的正文、人物、谜题答案或图片。

公开仓库不代表额外授予素材的再分发授权；如需转载或改编，请联系项目作者。
