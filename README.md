# 缺名册

中文校园悬疑 ARG 网页游戏。校庆征集旧照片时，一本旧书让两位毕业十年的同学发现：班级名单少了一个人。

[开始游玩](https://quemingce.github.io/linlan-missing-name/)

## 游玩

通过学校官网、私人资料与游戏内仿微信手机调查。包含声音索引、四片残页、资料对照和三种结局。无需账号，无需安装。

进度保存在当前浏览器。“继续游戏”下方及设置中可重新开始；设置中可导入、导出存档。新版沿用原公开版本的存档位置。

## 内容提示

本作人物、学校、组织和事件均属虚构，包含邪教、失踪、心理控制、怪异眼部图像、暗红画面及短音。对相关内容敏感的玩家请勿游玩；感到不适请立即停止。游戏中的消息与移交均为剧情模拟，不会联系真实个人或机构。
