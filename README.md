# 缺名册

一份毕业名册少了一个名字。你的老同学问：**我们班，原来有多少人？**

中文校园悬疑 ARG 网页游戏。以学校官网、个人聊天、旧论坛和档案副本展开调查，包含三种结局。当前为开发试玩版 v0.9.4。

## 游玩

打开发布后的网页，先阅读周栩的邮件与内容提示。通过搜索、仿微信手机对话、两处密码谜题和两处纸面小谜题推进。后半段为连续剧情，不需要填写调查长表。卡住时可以使用三级提示，不需要查看源代码。

- 支持电脑与手机浏览器；无需登录或 AI 服务。
- 进度、笔记和聊天记录保存在当前浏览器，可导出存档换设备继续。
- 可关闭动态效果，或单独隐藏恐怖图像与场景；不影响线索与结局。
- 设计目标为 45—70 分钟，尚未完成外部玩家的盲测计时。

## 内容提示

包含虚构邪教、失踪、心理控制、怪异眼部图像与压抑情节，无自动音效或高频闪烁。对内容敏感者请勿游玩；出现不适请立即停止。人物、学校、组织与调查结果均为虚构，游戏中的通信与提交不会联系真实个人或机构。

## 本地运行

在本目录执行：

```sh
python3 -m http.server 8768
```

访问 `http://127.0.0.1:8768/`。使用相对路径，可直接部署到 GitHub Pages 的项目目录或其他静态网站空间。

## 素材说明

校园影像与校徽沿用项目作者提供并授权参考的废弃模板素材，只用于虚构校园日常展示，不对应故事内的违法者或失踪者。眼部纹理、暗红底片背景、守灯像和走廊画面由 AI 为本项目生成。未复制参考游戏的正文、人物、谜题答案或图片。

公开仓库不代表额外授予素材的再分发授权；如需转载或改编，请联系项目作者。

## v0.9.1 恐怖内容更新

新增守灯像及眼睛拼贴页、私人检索异常、封存文件全屏封面、归灯诵词、点名覆盖页、走廊四帧与坏结局身份替换。三眼图册增加暗红背景，三只眼睛统一跟随鼠标。强烈的自动异常只在指定检索与封存文件触发；减少动态效果时跳过自动触发，隐藏恐怖场景后保留正文与全部核心线索。

## v0.9.2 页边残字

守灯像与归灯页新增乱码附签、重复压印和边缘残字。可点击辨认并合上；正文线索保持原样。动态开启时每九秒只替换一行装饰乱码，减少动态效果时保持静止，隐藏恐怖场景后一起隐藏。

## v0.9.3 开场简化

开场邮件去掉两项画面设置勾选框，阅读提示后直接进入游戏。再次打开邮件不会覆盖已有的游玩设置。

## v0.9.4 阅读、纸面解谜与仿微信手机

- 最终 7 项事实输入和 6 项证据下拉选择，改为三段有来源的共同阅读；不要求逐一打开全部档案。
- 保留留存包和档案柜两处密码。工作台改由资料员核对复写联后提供入口。
- 新增求助纸条拼接、新旧接送通知对照，错误有直接提示，刷新保留操作进度。
- 聊天附件直接发送，不再从全部已读资料里挑选。新增两段人物对话。
- 仿微信手机可覆盖在当前网页上查看；有联系人、消息提醒、聊天气泡和附件。旧附件过期、撤回提示与坏结局“用户已注销”均为预写的虚构界面，不连接微信或真实账号。
- 坏结局的代发消息和账号注销统一在手机中呈现，移除重复的网页四步联系记录；结局正文保留名册少一人的结果。
- 修复首次赴约邀请停在原地址、点击登记没有切换的问题。
- 已通过 16 项核心检查、检索权限边界检查；本次通过浏览器从新存档推进并验证三种结局与返回选择，单击交互、纸条拼接刷新续接、390px 布局均已检查。旧版已完成的调查不会被清除。

时长仍为设计目标，GPT 通关和自动化检查不能替代真人首次游玩的计时与体验反馈。
